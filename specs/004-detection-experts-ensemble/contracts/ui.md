# Контракт: изменения консоли (фича 004)

Страницы, формы, CSRF, автообновление и безопасность — как в
[../../003-soc-console-ui/contracts/ui.md](../../003-soc-console-ui/contracts/ui.md). Здесь —
только новое. Все подписи — по-русски, время — UTC, без inline-скриптов и стилей.

## Детали алерта — фрагмент `GET /fragments/alerts/{run_id}/{flow_uid}/probs`

К вероятностям 003 добавляется блок **«Эксперты»** (FR-019, SC-006):

| Элемент | Содержимое |
|---|---|
| Объяснение | строка `explanation` крупно, первой — ответ «почему это алерт» |
| Таблица экспертов | эксперт (русское имя), скор, порог эксперта, «сработал: да/нет» |
| Итоговый вердикт | вариант модели прогона (`ансамбль …`/`детектор …`), итоговый скор и порог |
| Направление | для `reversed`: «Ответный поток: атакующая сторона — `<IP>`, исходное направление `src → dst`» |

Для прогона до ансамбля — одна строка «Прогон сделан до появления ансамбля: один детектор
`<версия>`», остальное как в 003.

Русские имена: `classifier` — «классификатор атак», `anomaly` — «детектор аномалий»,
`meta` — «мета-слой».

## Карточка инцидента — `GET /incidents/{id}`

- В сводке: блок **«Кто поднял алерты»** — по экспертам и сочетаниям (`experts_summary`),
  с подписью «алерт, поднятый двумя экспертами, учтён у обоих»; для старых прогонов —
  пометка «прогон до ансамбля».
- В таблице алертов: колонка/значок «ответный» для `reversed`; колонка «эксперты» (коротко:
  «К», «А», «К+А», «М»), с расшифровкой в легенде.
- Класс `anomaly` везде подписан «аномалия (класс неизвестен)»; у действия — правило
  «класс атаки неизвестен → требуется ручной разбор».

## Список и панель

- Фильтр «Класс атаки» содержит «аномалия (класс неизвестен)».
- Панель прогона: строка «Модель прогона» и счётчики «алертов по экспертам», «ответных
  потоков». Счётчики кликабельны там, где у них есть фильтр списка (класс `anomaly`).
- Метки 003 («подозрительный источник») остаются подсказкой и считаются по `src_ip`
  инцидента, который теперь означает атакующую сторону.
