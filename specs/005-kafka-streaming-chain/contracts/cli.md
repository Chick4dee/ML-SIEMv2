# Контракт: командная строка (фича 005)

Запуск из корня: `uv run mlsiem <группа> <команда>`. Коды возврата, stdout/stderr и язык — как в
002 ([../../002-detection-incident-chain/contracts/cli.md](../../002-detection-incident-chain/contracts/cli.md)).
Команды 001–004 не меняют поведения. Новые группы — `stand` и `stream`, общая опция группы —
`--config configs/stream.yaml`.

## `stand` — брокерная машина (US1)

```
mlsiem stand seed-iso [--out var/stand/seed.iso]
mlsiem stand check
```

- `seed-iso` — собрать seed-ISO автоустановки из шаблонов `stand/broker/` и параметров конфига
  (SSH-ключ хоста берётся из `~/.ssh/id_ed25519.pub`; если его нет — понятная ошибка с командой
  создания). Ничего в системе не меняет, кроме файла.
- `check` — с хоста: адрес хоста в служебной сети, доступность брокера (≤ `connect_timeout_s`),
  версия, список топиков и их настройки, отсутствие брокера в сети стенда (у ВМ брокера нет
  адаптера в `lab_switch` — проверка через `Get-VMNetworkAdapter` в PowerShell только чтение).
  Код `0` — всё в порядке; `1` — с перечнем проблем и подсказками («машина выключена:
  Start-VM mlsiem-broker»).

Создание сетей и машины — PowerShell-скрипты `stand/hyperv/*.ps1` (запускает владелец, от
администратора; каждый меняющий шаг — с подтверждением, `-WhatIf` — только план):

| Скрипт | Делает |
|---|---|
| `00-check.ps1` | проверки и план без изменений |
| `10-network.ps1` | коммутаторы `mlsiem-mgmt` (Internal) и `mlsiem-lab` (Private), адрес хоста |
| `20-vm-broker.ps1 -Iso <ubuntu.iso> -Seed <seed.iso>` | ВМ Gen2, Secure Boot (UEFI CA), адаптеры mgmt + Default Switch |
| `30-post-install.ps1` | отключить адаптер Default Switch, извлечь ISO, `mlsiem stand check` |
| `90-remove.ps1` | удалить ВМ и коммутаторы |

Все идемпотентны: повторный запуск сообщает «уже есть» и ничего не ломает.

## `stream replay` — производитель (US2)

```
mlsiem stream replay --split unsw_time --part test [--limit N] [--speed 60|max] [--data-dir data]
mlsiem stream replay --pcap FILE [--speed 60|max]
mlsiem stream replay ... --resume SOURCE_ID
```

- Порядок — по времени начала потока; `--speed N` — паузы по времени трафика / N; `max` — без пауз.
- В stderr — прогресс раз в секунду (отправлено, потоков/с, отставание от графика).
- В конце отправляет `end`, ждёт подтверждения доставки всего; stdout: `source_id`, отправлено,
  время, средняя скорость.
- Отказ (код `1`) до отправки: брокер недоступен, нет разбиения/файла, у данных несовместимая
  или отсутствующая версия схемы. Ошибка посреди — код `1`, «отправлено N из M»,
  `--resume <source_id>` продолжит с первого неподтверждённого.

## `stream consume` — онлайн-цепочка (US3, US4)

```
mlsiem stream consume [--model DIR] [--once]
```

- `--model`/`--detector` — как у `soc run` (004): по умолчанию ансамбль, иначе детектор.
- До первого чтения: загрузка и проверки модели, миграция базы, аренда потребителя. Живая
  чужая аренда → код `1` «уже работает потребитель <хост:PID> с <время>».
- Работает, пока не остановят (Ctrl+C → доделать текущую пачку, записать, подтвердить, статус
  сеансов `stopped`, код `0`). `--once` — обработать всё доступное и выйти (для тестов и сравнения).
- stderr: раз в 10 с строка показателей; stdout при выходе: сводка по сеансам.

## `stream status`, `stream close`, `stream compare`

```
mlsiem stream status
mlsiem stream close --session RUN_ID
mlsiem stream compare --session RUN_ID --batch RUN_ID [--reports-dir reports]
```

- `status`: брокер (жив/нет, конец партиций), потребитель (аренда: жив/нет), по сеансам — статус,
  обработано, отставание (сообщений, секунд), задержка p50/p95, отвергнутые, опоздавшие,
  последняя активность.
- `close`: `running|stopped → completed` с записью в аудит; для уже завершённого — сообщение, код `0`.
- `compare`: отчёт `reports/stream_compare_<session>.{md,json}`; stdout — «эквивалентно» или
  число расхождений по видам. Код `0` в обоих случаях (это результат проверки); `1` — прогона нет
  или модели прогонов различаются.

## `soc run` (без изменений в вызове)

Пакетный прогон пишет `mode = batch`, `status = completed`; поведение прежнее (SC-008).
