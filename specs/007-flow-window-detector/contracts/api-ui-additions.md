# Контракт API и консоли: дополнения 007

Только добавления (как в 003–005): существующие поля, маршруты и их смысл не меняются. Тесты
строгих наборов ключей дополняются константами `*_KEYS_007`.

## API `/api/v1`

### Алерт (в карточке инцидента и в списке алертов)

Новые поля:

| Поле | Тип | Смысл |
|---|---|---|
| `kind` | `"flow" \| "window"` | вид алерта (`alerts.alert_kind`); у прогонов до 007 — `"flow"` |
| `window` | object \| null | разобранный `window_info` (data-model); `null` у алертов потоков |

У алерта окна `src_port`, `dst_port`, `protocol` = `null`, `flow_uid` = `window_id`.

### `GET /api/v1/incidents/{id}/alerts`

- Новый параметр `kind=flow|window` (без него — все алерты, как раньше).

### `GET /api/v1/incidents`

- Новое поле инцидента `n_window_alerts` (int, 0 для прогонов до 007).
- Новый фильтр `has_window_alerts=true|false`.

### `GET /api/v1/runs`

- У прогона новое поле `windows` (object | null) — раздел `summary.windows` (data-model
  «Прогон / сеанс»); `null` = прогон до 007.

### `GET /api/v1/stream/status` (показатели 005)

- Для сеанса с экспертом окон: `n_open_windows`, `n_windows_closed`, `n_window_alerts`,
  `n_window_late_dropped`.

## Консоль

- **Список инцидентов**: значок «окна» у инцидентов с `n_window_alerts > 0`; фильтр «есть
  алерты окон».
- **Карточка инцидента**:
  - у каждого алерта метка «поток» или «окно»; переключатель «все / потоки / окна»;
  - алерт окна раскрывается блоком: интервал (UTC), число потоков (с пометкой «усечено до 128
    для нейросети», если так), цели с числами, число портов назначения, пояснение, таблица до
    20 самых подозрительных потоков окна (flow_uid, цель, порт, протокол, скор потоковой модели)
    и до 5 самых влиятельных признаков окна (для бустинга);
  - гистограмма алертов (003, FR-011a) раскрашивает алерты окон отдельно.
- **Панель прогона**: «эксперт окон: <вид> <версия> (принят / принудительно / не принят / нет)»,
  число окон и алертов окон; у онлайн-сеанса — блок «Окна»: открыто, закрыто,
  опоздавших-вне-окна.
- Время — в UTC, как во всей консоли. Решения аналитика по инцидентам — без изменений
  (конституция V).
