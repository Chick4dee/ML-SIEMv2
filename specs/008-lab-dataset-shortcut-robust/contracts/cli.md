# Контракт CLI: группа `mlsiem lab` (дополнение к 006)

Команды 006 (`stand check`, `lab scenario …`, `lab demo`, `lab dataset build`, `lab evaluate`) не меняются
по смыслу; новые флаги необязательны. Все команды работают с хоста; действия на машинах стенда —
только по подтверждению (`--yes` пропускает вопрос в неинтерактивном режиме).

## `lab tools check`

Проверяет наличие инструментов сценариев и нормы на всех источниках, печатает версии и пишет их в
манифест. Код 0 — все доступны; 3 — часть недоступна (перечень), 2 — нет связи с машиной.

## `lab plan --seed N [--repeats 10] [--out var/lab/plan.json]`

Строит план сбора по конфигу (`collection`). Печатает: число запусков, оценку времени, состав по
классам/инструментам/источникам, долю резерва «неизвестное». Детерминирован по сиду и хешу конфига.

## `lab collect --plan var/lab/plan.json [--resume] [--yes] [--stop-after N]`

Исполняет план: проверка готовности и памяти (`stand check`), подтверждение старта (длительность и
объём записи), запуски с паузами, непрерывная норма, журнал. `--resume` продолжает по `collect_state.json`: пропускает
выполненные запуски и повторяет прерванные целиком (новая попытка). Код 0 — план выполнен, 4 — прерван (можно продолжить), 2 — стенд не готов.

### `lab collect stop [--now]` и `lab collect status`

`lab collect stop` — мягкая остановка (дожидается конца запуска и дренажа, печатает «можно выключать»);
`--now` — срочная (прерывает запуск, пишет `aborted`). `lab collect status` — прогресс, число сеансов,
оценка времени, признак `safe_to_power_off`. Остановка работает и из другого окна (стоп-флаг рядом с
планом). Код выхода `lab collect` при остановке — 4 (можно продолжить).

## `lab dataset build --pcap … --journal … [--plan …] [--version V]`

Расширение 006: принимает план, добавляет метаданные варианта, инструмента, источника, запуска,
повтора и части; пишет манифест (инструменты, версии, сид, хеш плана) и `quality.json`.

## `lab quality --dataset V`

Выводит отчёт качества и вердикт `clean` / `suspect` (код 0 / 5). Не требует стенда.

## `lab shortcuts --dataset V [--seeds 0 1 2] [--model-config …]`

Оценки «исключение инструмента» и «исключение хоста» и аудит признаков окружения; пишет
`shortcuts.json`, отчёт `reports/lab_shortcuts_<V>.md`, эксперимент MLflow `lab`, запись в журнал.

## `lab unknown --dataset V [--seeds 0 1 2]`

Раздел «неизвестные атаки»: способы оценки неизвестного и их объединение по резервным вариантам и классам целиком (leave-class-out) набора. Модель — LightGBM, обученный на train самого набора (`--model` не принимается: сырые логиты под классы стенда есть только у неё; перенос готовой модели измеряет `lab evaluate`). Пишет
`unknown.json`, отчёт `reports/lab_unknown_<V>.md` (с оговоркой FR-023), MLflow, журнал.

## `lab evaluate` (расширение)

Добавляется разбивка поимки по инструментам и источникам (`--by tool,source`) и доли ложных
срабатываний 0,1% / 1% / 5%.

## Коды выхода (общие)

`0` успех · `2` стенд не готов или нет данных · `3` часть инструментов недоступна · `4` сбор прерван ·
`5` вердикт `suspect` (не ошибка, сигнал владельцу).
